# 🎈 لعبة الحروف — Letters Game

لعبة تعليمية للأطفال لتعلّم الحروف **العربية** و**الإنجليزية** مع الكلمات والصور، وتدريبات واختبار بالنجوم.

## ✨ المميزات
- 📖 **تعلّم**: كل حرف مع كلمة وصورة، والنطق بالضغط على البطاقة.
- 🎤 **تدرّب على النطق**: استمع ثم كرّر، مع زر «نطقتُه»، وتعرّف صوتي اختياري (يحتاج إنترنت).
- ✏️ **تدريبات** وجمع النجوم 🏆 **اختبار** من 10 أسئلة (حرف ← كلمة، كلمة ← حرف، صوت ← حرف) مع حفظ أفضل نتيجة.
- 🔊 **الأصوات مدمجة بالكامل**: مُصنّع كلام داخل الكود (Web Audio) — لا ملفات صوتية ولا أصوات نظام ولا إنترنت.
- 📴 **تعمل بدون إنترنت** (PWA): بعد أول فتح يُخزَّن كل شيء، ويمكن تثبيتها على الهاتف.
- 🔇 زر كتم الصوت، وواجهة تتحوّل لـ LTR في الإنجليزية.

## 📁 الملفات
```
index.html              الصفحة الرئيسية
style.css               التصميم
js/data.js              الحروف والكلمات والنصوص
js/synth.js             مُصنّع الصوت المدمج
js/app.js               منطق اللعبة
sw.js                   العمل بدون إنترنت (Service Worker)
manifest.webmanifest    إعدادات التثبيت كتطبيق
icons/                  الأيقونات
.nojekyll               يمنع معالجة Jekyll في GitHub Pages
```

## 🚀 الرفع على GitHub ونشرها (GitHub Pages)
1. أنشئ مستودعاً جديداً **Public** على GitHub.
2. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع (Add file ← Upload files، واسحب الملفات والمجلدين `js` و`icons`).
3. من **Settings ← Pages** اختر: Source = `Deploy from a branch`، Branch = `main` و `/ (root)` ثم Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/` — افتحه مرة واحدة بالإنترنت وستعمل بعدها بدونه.

> للتجربة محلياً: افتح `index.html` مباشرة (الصوت واللعب يعملان؛ أما التخزين للعمل بدون إنترنت فيحتاج رابط http/https).

## 🔄 عند تعديل الملفات لاحقاً
غيّر `VERSION` في أول ملف `sw.js` (مثل `v2`) ليحصل المستخدمون على التحديث.

## 📱 تحويلها إلى APK
بعد النشر على GitHub Pages استخدم [PWABuilder](https://www.pwabuilder.com) بإدخال رابط الصفحة لتوليد حزمة Android.

## ℹ️ ملاحظة عن الصوت
الأصوات مولَّدة رياضياً داخل التطبيق (صوت اصطناعي مبسّط)، لذلك تعمل في كل مكان بدون إنترنت، لكنها تبدو آلية مقارنة بصوت إنسان. لتحسين النطق يمكن تعديل رموز `nm` (اسم الحرف) و`wp` (الكلمة) في `js/data.js`.
